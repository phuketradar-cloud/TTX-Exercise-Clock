# MTF Range Boxes (Pine Script v5)

อินดิเคเตอร์สำหรับ TradingView ที่วาด "กรอบราคา" (High-Low box) ของแต่ละไทม์เฟรม M1, M15, H1, H4, D1 ทับบนชาร์ตหลักพร้อมกัน โดยกรอบจะอัปเดตราคาสูงสุด/ต่ำสุดแบบเรียลไทม์ตามแท่งที่กำลังก่อตัวของแต่ละไทม์เฟรม

## วิธีใช้งานบน TradingView

1. เปิดชาร์ตที่ต้องการใน TradingView
2. ไปที่ **Pine Editor** (แท็บด้านล่างของหน้าจอ)
3. สร้างสคริปต์ใหม่ แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ [`mtf-range-boxes.pine`](./mtf-range-boxes.pine) ไปวาง
4. กด **Add to Chart**
5. ปรับการตั้งค่าได้จากหน้าต่าง **Settings** ของอินดิเคเตอร์:
   - เปิด/ปิดการแสดงกรอบราคาของแต่ละไทม์เฟรม (M1/M15/H1/H4/D1)
   - เลือกสีกรอบของแต่ละไทม์เฟรม
   - ปรับระยะยื่นกรอบไปทางขวา และเปิด/ปิดป้ายราคา High/Low

## หลักการทำงาน

สคริปต์ใช้ `request.security()` ดึงค่า High/Low ของแท่งกำลังก่อตัวในแต่ละไทม์เฟรม แล้ววาดเป็นกล่องเล็ก ๆ **ติดอยู่ทางขวาของแท่งเทียนล่าสุดเสมอ** (ไม่ลากยาวย้อนไปจากจุดเริ่มต้นของแต่ละไทม์เฟรม) โดยกล่องจะอัปเดตทุกครั้งที่มีแท่งใหม่/ราคาขยับ (`barstate.islast`) แต่ละไทม์เฟรมมีช่อง (slot) ของตัวเองเรียงต่อกันไปทางขวา จึงไม่ทับกันและอยู่ตรงราคาปัจจุบันตลอดเวลา

> หมายเหตุ: ถ้าเคยกด "Add to Chart" หลายครั้งตอนแก้โค้ด อาจมีอินดิเคเตอร์ตัวเก่าซ้ำค้างอยู่บนชาร์ต ให้เปิดรายการ indicator ที่มุมซ้ายบนของกราฟแล้วลบตัวที่ซ้ำออก เหลือไว้ตัวเดียว

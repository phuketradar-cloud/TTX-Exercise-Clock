# MTF Range Boxes (Pine Script v5)

อินดิเคเตอร์สำหรับ TradingView ที่วาด "กรอบราคา" (High-Low box) ของแต่ละไทม์เฟรม M1, M15, H1, H4, D1 ทับบนชาร์ตหลักพร้อมกัน โดยกรอบจะอัปเดตราคาสูงสุด/ต่ำสุดแบบเรียลไทม์ตามแท่งที่กำลังก่อตัวของแต่ละไทม์เฟรม

## วิธีใช้งานบน TradingView

1. เปิดชาร์ตที่ต้องการใน TradingView
2. ไปที่ **Pine Editor** (แท็บด้านล่างของหน้าจอ)
3. สร้างสคริปต์ใหม่ แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ [`mtf-range-boxes.pine`](./mtf-range-boxes.pine) ไปวาง
4. กด **Add to Chart**
5. ปรับการตั้งค่าได้จากหน้าต่าง **Settings** ของอินดิเคเตอร์ (คลิกไอคอนเฟือง ⚙️ ที่ชื่ออินดิเคเตอร์บนกราฟ) แท็บ **Inputs**:
   - แต่ละไทม์เฟรม (M1/M15/H1/H4/D1) มีหัวข้อกลุ่มของตัวเอง ในกลุ่มจะมีสวิตช์ "เปิดกรอบ" + ช่องเลือกสี อยู่แถวเดียวกัน กดสวิตช์เพื่อเปิด/ปิดกรอบของ TF นั้นได้ทันที
   - หมายเหตุ: Pine Script ไม่รองรับปุ่ม/แท็บที่คลิกได้บนตัวกราฟโดยตรง การเปิด-ปิดกรอบแต่ละ TF ต้องทำผ่านหน้าต่าง Settings นี้เท่านั้น

## หลักการทำงาน

สคริปต์ใช้ `request.security()` ดึงค่า High/Low ของแท่งกำลังก่อตัวในแต่ละไทม์เฟรม แล้ววาดเป็นกรอบสี่เหลี่ยม **ครอบอยู่ตรงตำแหน่งแท่งเทียนจริงของช่วงเวลานั้นบนกราฟ** (ไม่ใช่กล่องลอยไปทางขวา) โดยระหว่างที่ช่วงเวลานั้นยังไม่จบ กรอบจะขยายกว้างขึ้นและปรับสูง/ต่ำตามราคาที่เกิดขึ้นจริงไปเรื่อย ๆ

เมื่อช่วงเวลานั้นจบลง (เช่น พอครบ 1 ชั่วโมงสำหรับกรอบ H1) กรอบจะ "หยุดนิ่ง" ค้างอยู่ตรงตำแหน่งเดิมกลายเป็นประวัติ แล้วเริ่มวาดกรอบใหม่สำหรับช่วงเวลาถัดไป ผลลัพธ์คือจะเห็นแถวของกรอบต่อ ๆ กันไปตามช่วงเวลาบนกราฟ เหมือนภาพตัวอย่าง กรอบที่เก่าที่สุดจะถูกลบออกอัตโนมัติเมื่อจำนวนกรอบเกิน 100 กรอบ (ปรับได้ที่ `max_boxes_count` ในโค้ด)

> หมายเหตุ: ถ้าเคยกด "Add to Chart" หลายครั้งตอนแก้โค้ด อาจมีอินดิเคเตอร์ตัวเก่าซ้ำค้างอยู่บนชาร์ต ให้เปิดรายการ indicator ที่มุมซ้ายบนของกราฟแล้วลบตัวที่ซ้ำออก เหลือไว้ตัวเดียว
